# Paran Signature | Salon & Aesthetics

A premium, modern, SEO-optimized website for **Paran Signature | Salon & Aesthetics** — a luxury beauty salon and aesthetics studio located in Sheikhupura, Pakistan.

## 🌟 Features

- **Fully Responsive Design** — Desktop, tablet, and mobile optimized
- **SEO Optimized** — Meta tags, Open Graph, Twitter Cards, Schema.org markup
- **Premium Aesthetics** — Luxury color palette (White, Black, Gold, Beige)
- **Smooth Animations** — Scroll-triggered fade-ins, hover effects, glassmorphism
- **Sticky Navigation** — Glassmorphism header with active section tracking
- **Image Lightbox** — Gallery with full-screen viewing
- **FAQ Accordion** — Expandable questions section
- **WhatsApp Integration** — Floating chat button + form submission via WhatsApp
- **Click-to-Call** — Direct phone call links
- **Contact Form** — With appointment booking capabilities
- **Google Maps Embed** — Location showcase
- **Back to Top Button** — Smooth scroll navigation
- **Preloader Animation** — Elegant brand introduction
- **Scroll Progress Bar** — Visual navigation indicator
